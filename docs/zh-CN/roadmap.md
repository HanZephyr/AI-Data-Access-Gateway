# 路线图

[English Roadmap](../en/roadmap.md)

## 规划原则

- 当前代码、测试与可运行配置是唯一事实来源
- 路线图条目表示规划方向，不代表已经实现的能力
- 版本名称用于表达阶段目标，不承诺具体发布日期
- 文档会优先反映已经落地的实现边界，而不是历史里程碑口号

## V1.0：当前 MVP 基线

当前仓库已经具备 V1 MVP 的核心基础：FastAPI 后端、控制平面数据库、API Key 鉴权、关系型数据源登记与扫描、只读运行时查询守卫、字段级治理、脱敏与运行时解密控制、审计日志、React + Vite 管理控制台，以及演示种子数据和 Docker Compose 运行路径。

## V1.1：开源与文档加固

这一阶段聚焦对外发布面的打磨，包括完善英文与中文文档、补齐治理文件、统一开源协作入口、增加 CI 与安全审计工作流，并让仓库的公开表述与当前真实实现边界保持一致。

## V1.2：运行与安全加固

下一阶段的重点会放在更安全的管理员认证模型、更加稳健的部署与配置实践、可观测性改进、工具链依赖审计收敛，以及面向真实演示和试点环境的更安全默认值。

## V2.0：企业能力基础

V2.0 面向更成熟的企业化基础能力，例如更强的管理员身份体系、更丰富的策略控制、更清晰的多角色运维边界，以及更适合较大团队协作的治理与审计能力。

## V3.0：生态扩展

更长期的方向是扩展更广泛的数据源支持、提升可扩展性与插件化能力、完善运行时与 MCP 生态集成，并让网关更容易嵌入多种 AI Agent 工作流和组织内部平台。
