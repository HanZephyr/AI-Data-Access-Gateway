# 行为准则

[English original](../../CODE_OF_CONDUCT.md)

## 我们的承诺

为了营造开放、友善且无骚扰的社区环境，我们承诺让每一位参与者都能在项目中获得尊重，不因年龄、体型、可见或不可见残障、族裔、性特征、性别认同与表达、经验水平、教育背景、社会经济地位、国籍、外貌、种族、宗教或性取向而受到区别对待。

我们承诺以有助于建设开放、欢迎、多元、包容且健康社区的方式行动和互动。

## 我们的标准

有助于建设积极社区环境的行为包括：

- 以尊重、体谅和耐心的方式沟通
- 真诚接纳不同观点与经验
- 建设性地提供和接收反馈
- 对错误负责，及时修正，并从经历中学习
- 以项目整体利益为出发点做出判断

不可接受的行为包括：

- 使用带有性意味的语言或图像，以及任何不受欢迎的性关注
- 针对个人的人身攻击、侮辱性评论、恶意嘲讽或挑衅
- 公开或私下的骚扰行为
- 未经明确许可披露他人的私人信息
- 任何在专业协作环境中可被合理认为不当的其他行为

## 执行责任

项目维护者负责澄清并执行本行为准则，对任何不当、威胁、冒犯或有害行为采取适当且公平的纠正措施。

维护者有权删除、编辑或拒绝与本行为准则不一致的评论、提交、代码、Wiki 编辑、Issue 或其他贡献，并在适当时说明原因。

## 适用范围

本行为准则适用于所有项目空间，也适用于个人在公共场合代表项目时的行为。代表项目的例子包括使用官方项目邮箱、在官方社交媒体账号发言，或在线下/线上活动中担任正式代表。

## 执行

如果遇到辱骂、骚扰或其他不可接受行为，请通过仓库维护渠道联系项目维护者。所有报告都会被及时、谨慎地审查和调查。

所有社区负责人都有义务尊重事件报告人的隐私与安全。

## 执行指南

社区负责人会根据以下社区影响分级来决定违反本行为准则的后果：

### 1. 纠正

**社区影响：** 使用了不恰当的语言，或出现其他被认为不专业、令人不受欢迎的行为。

**处理结果：** 社区负责人会发出私下书面警告，明确指出违规性质并解释为何该行为不当。必要时，可能会要求公开道歉。

### 2. 警告

**社区影响：** 单次事件或一系列行为构成了违规。

**处理结果：** 发出正式警告，并说明若继续出现类似行为将产生进一步后果。在指定期间内，不得与相关人员互动，包括不得主动联系执行本行为准则的人员。这也包括避免在社区空间以及社交媒体等外部渠道继续相关互动。违反这些限制可能导致临时或永久封禁。

### 3. 临时封禁

**社区影响：** 严重违反社区标准，包括持续的不当行为。

**处理结果：** 在指定期间内，临时禁止其以任何形式与社区进行互动或公开沟通。在此期间，不允许与相关人员进行公开或私下接触，也不得主动联系执行本行为准则的人员。违反这些限制可能导致永久封禁。

### 4. 永久封禁

**社区影响：** 呈现出持续违反社区标准的模式，包括持续不当行为、针对个人的骚扰，或对某些群体表现出攻击性或贬损性言行。

**处理结果：** 永久禁止其在社区中进行任何形式的公开互动。
